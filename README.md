
This is a comprehensive multi-page web platform built for a catering and event management business. After finishing my smaller projects, I wanted to build something that looked and felt like a modern UK startup (think Togather or City Pantry). This project pushed me to think about UI/UX consistency and how to handle a lot of content across different pages without losing the user's attention.


Advanced Navigation: I implemented a fully responsive "hamburger" menu using the checkbox hack. It was a great exercise in pure CSS logic for mobile devices.

External Libraries: I integrated Flickity.js for the hero carousels to make the site feel more "premium" and interactive.

Component-Based CSS: Instead of one massive CSS file, I split my styles into nav_head_foot.css, primaryStyle.css, and style.css. This made debugging much easier when I was working on the "Book Now" or "Service" pages.

Smooth UX: I wrote a custom jQuery script to handle smooth internal page scrolling, so when users click "Contact Us" or "About," the transition feels professional.

Marketing Elements: I designed a comparison table (Dignans vs. Direct Booking) and a specialized mobile-friendly footer with SVG payment icons (Visa, Mastercard, Stripe), which are crucial for e-commerce credibility.


The "Typo" Lesson: If you look closely at the "Sign Up" buttons or the comparison table, you'll see I wrote "Sing Up" and "Dignans Carering." Honestly? I was so focused on the complex CSS layouts and the JavaScript integrations that I missed these typos in the final rush. I decided to keep them in this version because it reminds me to always run a spellcheck before a big "Go Live" — a mistake I only made once!

Asset Optimization: This was the first time I used .avif and .webp images alongside SVGs. Learning how to handle high-quality photography without killing the page load speed was a game changer.

SEO Fundamentals: I took meta-tags seriously here, adding descriptions, keywords, and robots-tags to ensure the site is indexable and professional.
